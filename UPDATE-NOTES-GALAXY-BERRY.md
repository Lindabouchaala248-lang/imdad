# IMDAD Premium 1.0 — Galaxy & Berry refinement

## Visual changes
- Galaxy banner is shorter and more horizontal: 292px desktop, 218px tablet/mobile, 190px narrow mobile.
- Reduced ambient star count from 170 to 96 and reduced their size.
- Softened nebula saturation and glow; retained blended indigo, violet and blue cloud-like gradients.
- Kept member stars as circular points and preserved click-to-open member cards, search and zoom controls.
- Removed Berry's full axial spin. Berry now has a restrained 3D hover effect with slight X/Y perspective, subtle lift and soft shadow. The thought bubble remains gently animated.

## Verification
- `npm run build` could not be completed in this environment because dependencies are not installed (`vite: not found`).
- Run `npm install` then `npm run build` locally before deployment.
- Demo orders and demo member records remain prototype data; they are not connected to a live backend.
